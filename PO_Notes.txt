


Features
-> Guests
	- Book a flight with instructor
	- Rent a plane
-> Students
	- Book a flight with instructor
	- Book a flight without instructor
	- Schedule a ground class with instructor
-> Instructors
-> Staff
	- Charge for flight
	- View all reservations
	- Make a reservation
-> Admin
	- Reports for all revenue & expenditure
-> Common
	- User creation
	- Roles management
	- Integration with Google

User
-> id
-> first_name
-> last_name
-> email
-> phone
-> date_of_birth
-> address_line1
-> address_line2
-> city
-> state
-> country
-> postal_code
-> date_created
-> date_updated

Role
-> id
-> name (student, guest, instructor, staff, admin, other)
-> date_created
-> date_updated

User_login
-> id
-> user_id
-> username
-> password (encrypted)
-> date_created
-> date_updated

user_roles
-> id
-> user_id
-> role_id
-> date_created
-> date_updated

aircraft
id
tail_number (this is the unique alphanumeric registration code on the plane)
serial_number (the factory alphanumeric serial Id number for the airframe)
make
model
year_built
flight_hours
fuel_capacity
weight
status (ready, maintenance, not_available)
current_airport_id
rental_rate (per hour)
next_inspection_date


reservation
id
user_id
aircraft_id (nullable)
instructor_id (nullable)
date_start (date & time)
date_end (date & time)
status (reserved, completed, canceled)
date_created
date_updated

instructor_schedule
id
instructor_id (foreign key with user_id with role of instructor)
date_start (date & time)
date_end (date & time)
activity_type (instruction, other, not_available)
date_created
date_updated
